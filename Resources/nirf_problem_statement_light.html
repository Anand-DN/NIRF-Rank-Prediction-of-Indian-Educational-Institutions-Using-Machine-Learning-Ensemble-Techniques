Problem Statement

NIRF Ranking Intelligence
& Analytics Platform

Build a web-based analytics and prediction platform that extracts NIRF ranking data from official PDF reports, transforms it into structured form, performs exploratory data analysis and statistical hypothesis testing, and applies machine learning to detect ranking bias, model feature importance, and forecast ranking trends across institutions and years — surfacing insights completely invisible in raw PDF rankings.
Four Core Gaps This Solves
📄
Data Locked in PDFs

NIRF publishes no API or dataset. Extraction pipeline is the first real engineering problem.

⚖️
Hidden Ranking Bias

Users see ranks, not the systemic patterns favouring certain institution types.

📈
No Trend Visibility

No tool lets institutions track rank movement or forecast future position over time.

🔬
No Statistical Proof

Observations about ranking patterns are never validated with rigorous statistical tests.

Trend Module
Prophet / ARIMA
Time-Series Rank Forecasting
  • Purpose-built for yearly trend forecasting
  • Prophet handles missing years gracefully
  • ARIMA good for univariate rank series
  • Cannot do multi-feature bias modeling
  • Needs sufficient historical points per institution
→ Separate module alongside XGBoost. Don't force XGBoost to do time-series.
Benchmark
Linear Regression
Naive Benchmark Only
  • Interpretable coefficients
  • Good sanity-check baseline
  • Assumes linearity — invalid for rankings
  • Cannot capture TLR × RPC interactions
  • Fails on non-Gaussian residual patterns
→ Include purely as benchmark. Its underperformance proves XGBoost is needed.
Skip
SVM / KNN / Neural Net
Not Suitable for This Problem
  • KNN fails on high-dimensional tabular data
  • SVM provides no native feature importance
  • Neural nets: overkill, uninterpretable here
  • None handle missing values natively
→ Theoretically possible. Practically wrong. Clear elimination strengthens your methodology.
🏆
Why XGBoost is the Definitive Choice
NIRF is structured/tabular — XGBoost's native domain
SHAP values directly power the bias analysis layer
Handles NaN from PDF extraction without imputation hacks
Non-linear TLR × RPC interactions captured automatically
Trains in under 10 seconds on NIRF dataset size
Feature importance explains which parameters drive rank most
